# Again

A phone practice desk for Advanced Web Page Design. The lessons are an Astro app. The pages to submit are plain HTML and CSS in `public/study`.

Live: https://again-liart-mu.vercel.app

## Run it

```bash
npm install
npm run dev
```

The terminal prints a Network address. On the same Wi-Fi, open that address on a phone.

## How a lesson goes

Start with the profile. The exam site comes after.

1. The lesson is first.
2. Try practice hides the lesson. No hint until a check fails.
3. A miss explains why. Two tries remain, then the lesson comes back and the count resets.
4. When the code passes, the assessment can start. The lesson stays closed until both answers are right.
5. The next lesson stays closed until that assessment is passed. Opening a later lesson by its address shows a closed gate.

Colours and Try stay available from the first screen. The bottom bar is Home, Profile, Exam, and Try. Say it again keeps one point and changes the words. Show all three leaves every wording on the screen.

Progress stays in this browser, in local storage. There is no account.

## Pages to submit

`public/study/profile` is the one-page profile. `public/study/cmsl` is the five-page site, with one external CSS file. Those pages use paper `#FAF7F2`, ink `#1A1712`, and clay `#C0532E`, in Arial. The desk is a dark reading surface so the lessons are easier to read. Do not copy the desk typeface into the assignment.
