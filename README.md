# Again

A phone practice desk for Advanced Web Page Design. The lessons are an Astro app. The pages she would submit are plain HTML and CSS in `public/study`.

```bash
npm install
npm run dev
```

The terminal prints a Network address. On the same Wi-Fi, open that address on her phone.

Start at the profile. The exam site comes after. The correct code stays closed until she takes two hints. The assessment stays closed until that practice code passes. Then the lesson closes until both answers are right. A miss says why, what to do, and what to remember. Colours are paper `#FAF7F2`, ink `#1A1712`, and clay `#C0532E`.
