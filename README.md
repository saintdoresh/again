# Again

A phone practice desk for Advanced Web Page Design. The lessons are an Astro app. The pages she would submit are plain HTML and CSS in `public/study`.

```bash
npm install
npm run dev
```

The terminal prints a Network address. On the same Wi-Fi, open that address on her phone.

Start at the profile. The exam site comes after. Each lesson opens on the teaching. Try practice hides it. A miss explains why, and two tries remain before the lesson comes back. When the code passes, she can start the assessment. The next lesson stays closed until that assessment is passed. The desk is a dark reading surface. The pages she submits stay paper `#FAF7F2`, ink `#1A1712`, and clay `#C0532E`.
